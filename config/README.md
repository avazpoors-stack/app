# پوشهٔ تنظیمات (config) — محل گذاشتن کلیدها و اطلاعات سرور

> این پوشه برای **تو** ساخته شده: هر چیزی که بعداً باید خودت وارد کنی (کلیدهای API، اطلاعات سرور و...) همین‌جاست.
>
> ⚠️ **قانون طلایی:** فایل‌های واقعی (بدون پسوند `.example`) هرگز وارد گیت‌هاب نمی‌شوند — در `.gitignore` هستند. فقط نمونه‌ها (با پسوند `.example`) در گیت ذخیره می‌شوند تا ساختار همیشه بماند و بدانی هر چیزی کجا می‌رود.

## الان چه کار کنم؟

**هیچ‌چیز!** تا آخرِ ساخت، اپ و سرور بدون هیچ کلیدی کامل کار می‌کنند (حالت آزمایشی/Mock — طبق نقشهٔ راه: «همه‌چیز اول ساخته می‌شود، خریدها آخر»).

وقتی زمان راه‌اندازی رسید (فاز آخر)، همین راهنما + راهنمای کامل `docs/SETUP_GUIDE_FA.md` (که در فاز آخر ساخته می‌شود) را دنبال می‌کنی.

## فایل‌های این پوشه

| فایل | برای چه | چه زمانی پر می‌شود |
|---|---|---|
| `backend.env.example` | تنظیمات سرور: رمز دیتابیس، کلید امنیتی، کلید نشان/زرین‌پال/کاوه‌نگار | فاز آخر (بعد از خرید سرویس‌ها) |
| `app.env.example` | کلیدهایی که داخل اپ اندروید می‌رود (نقشهٔ نشان، آدرس سرور) | فاز آخر (موقع ساخت APK نهایی) |
| `deploy.env.example` | اطلاعات سرور: آدرس (IP)، دامنه، نام کاربری | فاز آخر (بعد از خرید سرور) |

## روش کار (در فاز آخر — دقیقاً همین‌جا نوشته می‌شود)

1. از هر فایل `.example` یک کپی بدون پسوند `.example` بساز:
   ```bash
   cp backend.env.example backend.env
   ```
2. مقدارها را داخلش بگذار (کلیدها را از پنل هر سرویس می‌گیری — راهنمای خرید جدا داده می‌شود).
3. اسکریپت راه‌اندازی که در فاز آخر ساخته می‌شود، خودش از همین پوشه می‌خواند.
