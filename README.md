# بدنه (Badane) — پلتفرم ورزشی

اپلیکیشن اندروید «بدنه»: فیتنس + حرکت اصلاحی، آفلاین و آنلاین با هم.

## ساختار ریپو

```
app/       اپلیکیشن Flutter (اندروید)
server/    بک‌اند Python FastAPI
docs/      اسناد: مسترپلن، نقشه راه، پلن، مرجع طراحی
.github/workflows/  CI (تست + بیلد APK)
MEMORY.md  حافظهٔ دائمی پروژه (هر جلسه اول این را بخوان)
```

## مستندات اصلی

- `docs/PLAN.md` — پلن اجرایی نهایی (فازها P0..P8)
- `docs/ROADMAP.md` — نقشه راه و تصمیم‌های معماری
- `docs/BADANE_MASTERPLAN.md` — مسترپلن محصول
- `docs/DESIGN_REFERENCE.md` — مرجع طراحی (تم بام نارنجی-خاکستری)
